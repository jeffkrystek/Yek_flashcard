# 1. Project Authorization

This Project Charter formally authorizes the initiation of the Yek Flashcard project and grants authority to proceed with detailed planning, execution, monitoring, and project closure activities.

The project will be managed using Agile project management practices and documented throughout the complete software development lifecycle.

# 2. Project Purpose

Yek Flashcard is a dual-purpose initiative designed to:

1. Develop a production-quality cross-platform mobile flashcard application for beginner English–Farsi vocabulary learning.
2. Demonstrate professional software development and project management practices through publicly available documentation, version control, and portfolio artifacts.

The project will integrate product development with structured project management in order to showcase the complete lifecycle of planning, developing, testing, releasing, and maintaining a software product.

# 3. Project Objectives

The project will pursue the following high-level objectives:

## Product Objectives

- Develop a Flutter-based mobile application.
- Support beginner English–Farsi vocabulary learning.
- Provide offline study capabilities.
- Include native pronunciation.
- Release Version 1.0 for public use.
- Satisfies my desire for a flashcard focused learning experience

## Project Management Objectives

- Apply Agile project management methodologies.
- Produce comprehensive project documentation.
- Maintain version-controlled project artifacts.
- Track schedule, budget, scope, risks, and project performance.
- Conduct Sprint Reviews and Sprint Retrospectives throughout development.

## Portfolio Objectives

- Publish a professional portfolio website.
- Maintain a public GitHub repository.
- Publish reusable project management templates.
- Demonstrate complete project lifecycle documentation for prospective employers.

# 4. Business Justification

The project provides value in three primary areas:

### Product Value

Develop a focused vocabulary-learning application that emphasizes simplicity, offline accessibility, and future scalability.

### Professional Value

Create a comprehensive portfolio demonstrating software engineering and project management capabilities through a real-world software project.

### Educational Value

Produce reusable documentation and templates illustrating practical application of project management principles.

# 9. Assumptions

The project assumes:

- Flutter remains a suitable cross-platform framework.
- Approximately 10 hours per week are available for development.
- Native pronunciation resources will be available.
- Development will primarily be completed by a single individual.
- Required development tools remain available throughout the project.

# 10. Constraints

The project is constrained by:

- Solo development resources.
- Limited project budget.
- Part-time development schedule.
- Initial support for one language pair.
- Version 1 scope limitations.

# 13. Project Governance

The project will follow an Agile software development approach using iterative development cycles.

Project work will be managed using Jira, while source code and documentation will be maintained under version control using GitHub.

Project planning and reusable templates will be maintained in Notion.

Regular Sprint Planning, Sprint Reviews, and Sprint Retrospectives will be conducted throughout development.

# 14. Project Manager Authority

The Project Manager is authorized to:

- Develop detailed project plans.
- Manage scope, schedule, budget, and risks.
- Prioritize product backlog items.
- Approve routine project decisions.
- Coordinate testing and releases.
- Publish project documentation and portfolio materials.
