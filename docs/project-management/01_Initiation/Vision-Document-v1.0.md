# 1. Product Origin

Yek Flashcard began as a personal learning project. While studying Farsi, I searched for a lightweight flashcard application that emphasized quick vocabulary review, native pronunciation, offline functionality, and a distraction-free experience. Although several language-learning applications offered portions of this functionality, none matched the simple workflow I wanted for my own daily study.

Rather than adapting my learning process to existing tools, I chose to build the application myself.

As both the product creator and an intended end user, I can continuously evaluate design decisions through real-world use while applying professional software development and project management practices throughout the project's lifecycle. This dual perspective helps ensure that new features address practical learning needs while maintaining a disciplined product vision.

# 2. Vision Statement

Yek Flashcard aims to provide a simple, accessible, and effective language-learning experience through a mobile flashcard application designed for beginner English and Farsi learners.

The project will combine software development, product design, and professional project management practices to create a complete end-to-end software project. In addition to delivering a functional mobile application, the project will serve as a publicly documented case study demonstrating the planning, execution, monitoring, and completion of a software development initiative.

The long-term vision is to create a scalable language-learning platform that can support additional languages while demonstrating a repeatable framework for managing and delivering technology projects.

# 3. Project Background

Language-learning applications often provide extensive features including lessons, games, social interaction, and artificial intelligence tools. While these features can be valuable, they may create unnecessary complexity for users who primarily want a simple method to build vocabulary.

Yek Flashcard addresses this need by creating a lightweight flashcard application that prioritizes simplicity, accessibility, and ease of use.

# 5. Problem Statement

Many existing language-learning applications attempt to solve multiple learning challenges simultaneously, resulting in complex user experiences.

Beginner learners often need a straightforward tool that allows them to:

- quickly review vocabulary,
- hear accurate pronunciation,
- study at their own pace,
- and track personal improvement.

Additionally, aspiring software professionals benefit from demonstrating not only technical skills but also the ability to manage a complete project from concept through delivery.

# 6. Product Vision
