# 1. Executive Summary

Yek Flashcard is a software development project to design, build, and publish a cross-platform mobile application for beginner English–Farsi vocabulary learning.

In addition to delivering a functional language-learning product, the project serves as a comprehensive demonstration of professional software development and project management practices. The project will produce a publicly available portfolio that documents the complete software development lifecycle, including planning, execution, monitoring, and project closure.

The project is expected to generate value through multiple avenues, including mobile application revenue, professional portfolio development, reusable project management templates, and long-term expansion into additional language offerings.

# 2. Business Need

Language-learning applications often prioritize comprehensive educational ecosystems over simple vocabulary acquisition. Many learners, however, seek an easy-to-use application that allows them to practice vocabulary efficiently without unnecessary complexity.

At the same time, professionals seeking careers in software development or project management often lack publicly available examples demonstrating how they manage an entire software project from concept to delivery.

This project addresses both needs by developing a production-quality mobile application while publicly documenting the planning and management practices used throughout its development.

# 3. Problem Statement

Current language-learning applications may present challenges such as:

- Feature complexity that overwhelms beginner learners.
- Limited offline functionality.
- Subscription costs that discourage casual users.
- Interfaces that prioritize breadth over focused vocabulary practice.

Additionally, many software portfolios emphasize finished code but provide little visibility into the project management decisions that guided development.

This project seeks to demonstrate both technical implementation and disciplined project execution.

# 4. Proposed Solution

Develop a Flutter-based mobile flashcard application that provides:

- Beginner English–Farsi vocabulary.
- Native pronunciation.
- Offline study capability.
- Local progress tracking.
- A clean and intuitive user interface.

The project will also produce a complete set of professional project management artifacts, including planning documents, schedules, budgets, sprint documentation, risk management, and lessons learned.

All documentation will be maintained using professional tools including GitHub, Jira, Notion, and supporting project management software.

This project will fill the need of a focused flashcard experience that I have wanted to use myself.

# 7. Alternatives Considered

## Alternative 1 – Do Not Develop the Project

Advantages

- No financial investment.
- No development effort.

Disadvantages

- No software portfolio.
- No practical project management case study.
- No opportunity to publish an application.

## Alternative 2 – Develop Only the Mobile Application

Advantages

- Reduced documentation effort.
- Faster development.

Disadvantages

- Limited demonstration of project management capabilities.
- Reduced portfolio value.
- Less opportunity to showcase planning and execution skills.

## Alternative 3 – Develop Only Project Management Templates

Advantages

- Lower technical complexity.
- Faster completion.

Disadvantages

- No production software.
- Limited demonstration of software engineering capabilities.
- No integrated software development case study.

## Recommended Alternative

Develop both the mobile application and the complete project management portfolio.

This option provides the greatest long-term professional value by combining technical implementation with disciplined project management practices.
